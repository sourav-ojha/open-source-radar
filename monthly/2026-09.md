   PostgreSQL in one tab, self-hostable, direct stack match.

   multi-agent coding work that survives context loss between sessions.

   commands (`git reset --hard`, `rm -rf`) before a coding agent can run them unattended.

   cost than sandbox providers for agent-code-execution infrastructure.

7. **AgentSight** — 8.6 — PROTOTYPE — eBPF-based agent activity observability that works
   without owning the agent process or the model gateway.
8. **Dagu** — 8.5 — USE NOW — single-binary workflow/DAG orchestrator, no second platform
   to operate versus Airflow/Temporal.
9. **Graphify** — 8.5 — PROTOTYPE — knowledge-graph skill doubling as a personal
   "second brain" and documentation/onboarding tool.
10. **agent-device** — 8.5 — PROTOTYPE — closes the verification loop for agent-generated
    mobile/cross-platform UI changes.

## Emerging Patterns
- **A cheap, typed "judge model" as a decision-sidecar to the main generation model is
  becoming a recognized agent-engineering primitive**, not a single vendor's angle.
  Surfaced independently within the same week in Abide (rule enforcement), jevgrep
  (code search ranking), and mu (a 35-decision-point "judgment kernel"), all reachable
  through TypeSafe's "Jev" model or a pluggable equivalent. Worth tracking as a category
  even though none of the specific implementations are mature yet.
- **AI-agent observability kept fragmenting all month**, exactly as flagged in August's
  synthesis, but the fragmentation is now by *purpose* rather than by *layer*: AgentSight
  and Qtap watch agent/network *behavior* (security angle), Headroom/SIMURG/Laminar
  watch LLM *calls* (debugging angle), and this run's Agent Console watches *cost*
  (FinOps angle). Three legitimately different products now exist in what looked like
  one category in August.
- **Coding-agent skills went from a format (Vercel's `skills` CLI, catalogued in August)
  to an ecosystem** — dozens of skill repos, an evaluation/quality-gate framework from
  NVIDIA (SkillEvaluator, filed Worth Watching this run), and skills as the primary
  distribution mechanism for tools like jevgrep and Benjamin-Plus. Installing a skill is
  now a normal first step for adopting a coding-agent tool, not a side feature.
- **Self-hosted infrastructure hype waves arrived and were filtered weekly**: PaaS
  clones (late August), Terraform drift detectors, blue-green deployment tutorials,
  chaos-engineering-for-agents, clipboard sync, and voice/browser-agent waves (all
  September) each produced dozens of near-identical low-star entrants chasing a visible
  mainstream success. None were catalogued; the run notes/rejected list absorbed them
  weekly so they don't need re-litigating.
- **AGPL-3.0 remained disproportionately common among the most interesting self-hosted
  picks** (15 of 134 September entries, ~11%) — consistent with August's flag. Still not
  a blocker per AGENT.md, but still a standing diligence item before embedding any of
  them (Monoscope, SnapOtter, Vicoa, Router.so, Quackback, Macro among them) in a
  commercial product.

## Redundant Categories
- **AI & agent infrastructure / developer productivity** together account for over 100
  of September's 134 new entries once overlapping categories are combined — by far the
  most saturated area, as expected given September's rotation slots leaned AI-agent-
  heavy. Future entries in this space need a clearly distinct slice (as this run's Hippo
  memory-decay mechanic and Agent Console's FinOps framing both were) rather than another
  general-purpose coding-agent harness or generic MCP server.
- **Document processing / RAG infrastructure** (14 September entries on top of 5 from
  August) is the second most saturated area. Most differentiate on format (PDF-specific,
  HTML-specific) or pipeline stage (extraction vs. chunking vs. embedding vs. serving);
  genuinely novel angles are getting rarer.
- **Self-hosted SaaS alternatives** (17 combined across both "self-hosted SaaS
  alternatives" and "self-hosted SaaS alternative" category-label variants) is dense
  enough that this label should probably be normalized to one spelling in a future
  cleanup pass — a bookkeeping note, not a discovery finding.

## Potential Product Ideas
- **Agent cost/FinOps as a standalone micro-SaaS**, sharpened from August's version of
  this idea now that Agent Console has demonstrated a concrete cross-machine,
  presenting-mode design for exactly this — a hosted or self-hosted "see what your
  team's coding agents cost, per person, per client" product remains underserved even
  with Agent Console existing, since it's a single-vendor open-source tool, not a
  managed service.
- **A rule-enforcement layer for internal coding standards, sold as a service**, built on
  the same cheap-judge-model pattern as Abide but packaged for teams that don't want to
  manage their own TypeSafe/gateway key or hook wiring — Abide proves the economics work
  (fractions of a cent per edit); the packaging gap is the product opportunity.
- **A lightweight skill-quality gate for internal/product skills**, using
  SkillEvaluator's tiered approach (validation → dedup → live evaluation) as an
  architecture reference but scoped to a single team's private skill library rather than
  NVIDIA's public catalog pipeline — directly useful for building and maintaining
  Sourav's own growing set of Claude Code skills.
- **A decaying-memory layer for support/ops knowledge bases**, generalizing Hippo's
  "mark wrong → rank down → supersede" mechanic beyond coding-agent memory to any
  internal knowledge base (runbooks, support macros) that currently just accumulates
  articles without ever demoting the ones that turned out wrong — relevant to the MSSP
  admin-portal SaaS's own internal documentation.
