_Rotation slot 5 — self-hosted SaaS alternatives, productivity_

## Executive Summary
Today's slot leaned into the self-hosted-SaaS-alternative niche directly, and the signal-to-noise ratio was lower than usual: most sub-niches searched (personal finance trackers, link-in-bio pages, Calendly clones, e-signature tools) are either saturated same-day hype waves of near-identical vibe-coded MVPs, or already dominated by mainstream names Sourav almost certainly already knows (Documenso, DocuSeal, OpenSign). Two projects cleared the bar on real differentiation: a time-tracking/invoicing tool that has quietly built out genuine EU e-invoicing compliance (Peppol, Factur-X/ZUGFeRD, XRechnung) and deep accounting-system sync, and a social-media management platform that is unusual for shipping zero feature gating at all. ## Today's Best Discoveries

### 1. TimeTracker (DRYTRIX) — 7.7/10
**Decision:** USE NOW

**What it is** — Self-hosted time tracking, project management, and invoicing app (GPL-3.0, Flask/PostgreSQL) that generates EU-compliant e-invoices (Peppol BIS, Factur-X/ZUGFeRD, XRechnung), syncs with QuickBooks/Xero/Sage/DATEV, pushes entries to Gusto/ADP payroll, and includes a client portal with messaging.
**Why I should care** — It closes the full loop — track hours, invoice a client, get the invoice into accounting — in one self-hosted tool, and the EU e-invoicing compliance is exactly the kind of tedious regulatory-standard work not worth building from scratch.
**What it could replace** — A Toggl/Clockify subscription plus a separate invoicing tool (Bonsai/FreshBooks) plus manual CSV exports into accounting software.
**Ways I could use it** — Track billable hours for consulting/PTaaS-partnership work and invoice directly from tracked time; issue EU-compliant e-invoices to clients that require them; sync invoices into QuickBooks/Xero/Sage/DATEV; give a client a portal to approve invoices and message the team; export time entries to Gusto/ADP for payroll.
**Agent opportunity** — Ships a REST API (consumed by its own desktop/Flutter mobile apps) that's a reasonable base for a future invoicing/time-entry MCP wrapper, though none ships today.
**Integration effort** — Low — Docker image, Docker Compose, NAS templates (QNAP/Synology/Portainer), one-click Render deploy.
**Maturity** — Mature in practice despite modest stars: created 2025-08-15, 628 stars, releases shipping roughly weekly with a detailed CHANGELOG, currently v5.17.2 (2026-09-25).
**License** — GPL-3.0. Copyleft applies only if redistributing a *modified* version as software — self-hosting or running it for clients without distributing modified code doesn't trigger it.
**Alternatives** — solidtime (already catalogued, time tracking only, no invoicing/compliance); Toggl/Clockify/Harvest (SaaS); Bonsai/FreshBooks (invoicing only, no EU e-invoicing).
**Why this one** — None of the alternatives combine time tracking with real EU e-invoicing format compliance and multi-provider accounting sync in one self-hosted tool.
**Recommendation** — Install and validate the e-invoicing and one accounting-sync integration against a real client before fully replacing an existing paid tool.

### 2. BrightBean Studio — 7.1/10
**Decision:** PROTOTYPE

**What it is** — Open-source, self-hostable social media management platform (AGPL-3.0, Django/HTMX) covering Facebook, Instagram, LinkedIn, TikTok, YouTube, Pinterest, Threads, Bluesky, Google Business Profile, Mastodon, and DEV.to from one dashboard, with every feature available to every user.
**Why I should care** — It replaces a $100–300/month Buffer/Sendible/SocialPilot subscription entirely free, with no per-seat or per-channel limits, and talks directly to each platform's first-party API using your own credentials rather than through an aggregator middleman.
**What it could replace** — Buffer, Sendible, SocialPilot, or ContentStudio subscriptions; the multi-month effort of hand-building first-party integrations against 10+ platform APIs.
**Ways I could use it** — Run scheduling/publishing for a side project or client roster without per-seat fees; use the passwordless client portal for approval workflows; triage the unified social inbox across platforms; white-label branding if reselling as a service to existing MSSP/PTaaS clients.
**Agent opportunity** — None documented today; the webhook delivery system and Django views are a plausible base for a future automation layer, but that would be custom work.
**Integration effort** — Low — one-click Heroku/Render/Railway deploy, or Docker Compose.
**Maturity** — Emerging — created 2026-03-25 (~6 months old), 2,406 stars, 524 forks (a notably high fork ratio for its age, consistent with organic adoption rather than inflated stars), CI passing, but no tagged GitHub releases yet.
**License** — AGPL-3.0 — **flagged loudly**: if a modified instance is run as a service reachable by third-party users (e.g. reselling hosted access to clients), the modified source must be made available to those users. Self-hosting unmodified or for internal/owned use only does not trigger this.
**Alternatives** — Buffer/Sendible/SocialPilot/ContentStudio (SaaS); Postiz and several same-week "Buffer alternative" entrants (0–500 stars, far less mature).
**Why this one** — Zero feature gating plus genuinely first-party (non-aggregator) platform integrations is a combination not found in the dozen or so competing same-week entrants.
**Recommendation** — Stand up against one or two real social accounts to validate the integrations; get a clear answer on the AGPL hosting implication before any resale plan.
