# Open Source Radar — 2026-10-14
_Rotation slot 1 — AI agents, MCP, coding productivity_

## Executive Summary
Today's slot was dominated by three signals happening at once: an ongoing explosion of same-day, zero-star, templated skill/plugin/MCP-server repos with no vetting; a direct, credible response to that exact problem in the form of NVIDIA's own skill security scanner; and a recurring, suspicious pattern of inflated star counts turning up across several *unrelated* searches today (agent orchestration, context compression, Claude Code hooks, MCP security) at ratios of roughly 260:1 to 650:1 stars-to-watchers. The strongest finds otherwise sit in two already-known niches — agent-session memory and agent-output token compression — but differentiate clearly from what's already catalogued: a no-LLM memory tool built from logs agents already write, and a one-day-old but unusually rigorously engineered compression CLI.

## Today's Best Discoveries

### 1. SkillSpector — 8.7/10
**Decision:** USE NOW

**What it is** — NVIDIA's own security scanner for AI agent skills (Claude Code, Codex CLI, Gemini CLI, MCP), covering 71 vulnerability patterns across 17 categories (prompt injection, exfiltration, MCP tool poisoning, supply-chain risk, memory poisoning) via static AST/taint/YARA analysis plus an optional LLM pass, live CVE lookups via OSV.dev, and SARIF/JSON/Markdown output.
**Why I should care** — this run's own discovery pass surfaced dozens of same-day, zero-star, unvetted skill/plugin/MCP-server repos (see Rejected below); SkillSpector is a direct, low-effort check before installing any of them, backed by NVIDIA's own research claim that 26.1% of a 31,132-skill sample contained vulnerabilities and 5.2% showed likely malicious intent.
**What it could replace** — the manual "read the source before I trust it" step that realistically never happens at the pace skills/plugins are shipping right now.
**Ways I could use it** — gate skill/plugin installs behind a local scan; batch-scan an existing skills directory; wire SARIF into GitHub code scanning; diff MCP registry snapshots before trusting an update; baseline accepted findings for clean re-scans.
**Agent opportunity** — ships as CLI, Pi extension, OpenCode extension, and MCP server, so an agent can scan something before installing it, not just a human beforehand.
**Integration effort** — Low: `uv tool install` or Docker, no infra to run.
**Maturity** — Emerging (created 2026-03-21, v2.12.0, confirmed under the real NVIDIA org).
**License** — Apache-2.0, no commercial restrictions.
**Alternatives** — Tencent/AI-Infra-Guard (broader red-teaming platform), and a same-week wave of competing scanners (akto, panguard-ai, hol-guard, tooltrust-scanner, soup-wall) with no comparable verified-org backing or documented methodology.
**Why this one** — verified NVIDIA org account, 71 documented patterns, and a stated research methodology beat a crowded field of marketing-heavy entrants.
**Recommendation** — install and run it against anything added to an agent's skill/plugin directory going forward.

### 2. deja-vu — 8.0/10
**Decision:** PROTOTYPE

**What it is** — agent-session memory built entirely from the plaintext session logs Claude Code, Codex, Cursor, and 38 other harnesses already write to disk; no LLM, no embeddings, no server. Serves recall over MCP and hooks, claims to survive context compaction, syncs across machines over SSH.
**Why I should care** — every agent-memory tool catalogued so far (Hippo) extracts and scores memory with an LLM; this indexes what's already on disk, at zero added inference cost and no hallucination risk in the recall itself.
**What it could replace** — re-explaining a decision made in Codex to a fresh Claude Code session months later.
**Ways I could use it** — session-start auto-recall across a multi-agent workflow; manual search over any agent's history; marking a reverted decision so future hits warn it was tried and dropped; syncing session memory between two machines with no cloud step.
**Agent opportunity** — wires into MCP and hooks in one command; also drops a `SKILL.md` teaching an agent the CLI contract directly.
**Integration effort** — Low: single Go binary, ten-second install.
**Maturity** — Emerging (created 2026-07-14, v0.22.1, single maintainer).
**License** — MIT.
**Alternatives** — Hippo (already catalogued, LLM-based with a decay signal); MemPalace (evaluated previously, not catalogued — deja-vu benchmarks directly against it).
**Why this one** — the no-LLM, index-what's-already-there approach is a genuinely different design point from everything else in this niche so far, not just another entrant.
**Recommendation** — prototype across one real multi-agent project before trusting it as a daily driver; all benchmark numbers in its README are self-reported.

### 3. squeeze — 7.5/10
**Decision:** PROTOTYPE

**What it is** — a CLI that sits in a pipe between a tool and a coding agent, parsing Terraform/pytest/go test/checkov/trivy/tflint output and printing the smallest text that still carries every change or failure, guaranteeing sensitive values never reach stdout.
**Why I should care** — directly answers a linked GitHub issue in its own README where one Claude Code diagnostics call returned ~580,700 tokens; this is a concrete token-budget fix with zero agent-side integration beyond a pipe.
**What it could replace** — hand-rolled `tail -n 100` hacks in agent instructions that can cut past the one line that mattered.
**Ways I could use it** — pipe `terraform plan -json`, pytest, or go test output through it before an agent reads it; use `--fail-on` for a clean exit-code stop condition instead of prose-parsing.
**Agent opportunity** — designed to be dropped straight into an AGENTS.md/CLAUDE.md instruction file.
**Integration effort** — Low: `go install`, no release yet so pin a commit.
**Maturity** — Experimental (created yesterday, 4 stars, explicitly pre-1.0).
**License** — MIT.
**Alternatives** — Headroom (already catalogued, broader/general-purpose); Paritok (model-based compression gateway, heavier — needs hosting a 4B model).
**Why this one** — hidden-gem engineering quality (Terraform-corpus conformance tests, fuzzing, 95% coverage gate) that's unusual for a one-day-old repo, even though the repo itself is too new to trust unattended yet.
**Recommendation** — try it by hand on one real Terraform or pytest run; too new for anything automated.

## Small but High-Leverage Utility
**patient-zero** scans Node/Python projects and AI-agent configs for indicators of known npm/PyPI supply-chain attacks since September 2025 (maintainer-account-phish incidents, Shai-Hulud-style worms), with a mode that resolves a proposed install into a sandboxed temp directory and refuses to proceed on a match before any postinstall script runs. The specific angle that makes it worth 30 seconds — an AI agent installing a transitive dependency on your behalf, unsupervised — is a genuinely new risk, and npm audit's CVE database isn't the right tool for maintainer-phish incidents this recent. One caveat worth checking yourself: its npm package hasn't shipped a new version since 2026-05-14 despite recent GitHub activity, so verify the IoC database is actually fresh before leaning on it for a brand-new incident.
